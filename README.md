# Markdown Buddy – R Script Documentation

## Project Overview

This project documents an R script called `app.R`. The script is an exercise for building a basic user interface using the Shiny package in R.

## Purpose

The purpose of the script is to create a simple Shiny application. The user interface includes a heading, paragraphs, an image, and a slider.

## Inputs

The application includes a slider input called `my_slider`. The slider has a minimum value of 10, a maximum value of 100, and a default value of 50.

## Outputs

The script creates a Shiny web application with a user interface. It displays text, an image, and an interactive slider. A basic server function is also included so the Shiny application can run.

## How to Run

1. Open the R script in RStudio.
2. Make sure the Shiny package is installed.
3. Load the Shiny package.
4. Run the `app.R` script.
5. The Shiny application will open and display the user interface.
